حریم خصوصی و آمار بازدید

اطلاعاتی که این نسخه جمع‌آوری می‌کند شفاف است.

🔐 آمار ناشناس و اختیاری

فقط پس از انتخاب «پذیرش آمار ناشناس»، زمان ثبت‌شده توسط سرور، مرورگر تقریبی، سیستم‌عامل تقریبی، نوع دستگاه، صفحه و شناسهٔ تصادفی همان نشست ثبت می‌شود.

نام، نام خانوادگی و شماره تلفن فقط در پروفایل حساب ذخیره می‌شوند. IP هنگام ثبت‌نام/ورود برای امنیت حساب در جدول جداگانه ثبت می‌شود و فقط مدیر مجاز آن را می‌بیند؛ این داده با آمار ناشناس بازدید یکی نیست.

📥 راهنمای دریافت فایل‌ها

  • فقط از لینک‌های معتبر و منتشرشده استفاده کنید.
  • فضای خالی لازم و مشخصات دستگاه را پیش از دریافت بررسی کنید.
  • فایل‌های بازی بزرگ باید روی فضای میزبانی مناسب قرار بگیرند؛ GitHub Pages برای خود سایت است.

تنظیم حریم خصوصی

برای بهبود سایت می‌توانیم آمار ناشناس ثبت کنیم: زمان، مرورگر و سیستم‌عامل تقریبی، نوع دستگاه، صفحه و شناسهٔ تصادفی نشست. این آمار ناشناس از ثبت IP حساب جداست. اگر حساب بسازید یا وارد شوید، IP برای امنیت حساب ثبت می‌شود و مدیر می‌تواند آن را در پنل مدیریت ببیند. انتخاب آمار بازدید قابل تغییر است.
